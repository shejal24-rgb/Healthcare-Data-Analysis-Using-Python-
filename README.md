## 📌 Project Overview

This project analyzes healthcare data using Python to explore patient demographics, medical conditions, hospital visits, and treatment costs. It uses data analysis and visualization to identify patterns and summarize healthcare information.

## 🎯 Project Objectives

- Analyze patient age distribution.
- Compare patient counts by gender.
- Identify common medical conditions.
- Calculate average treatment costs.
- Compare treatment costs across hospitals.
- Explore the relationship between patient age and treatment cost.

## 🛠️ Technologies Used

- **Python** – Programming and analysis
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical calculations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization

## 📊 Dataset Information

The dataset contains 30 fictional patient records for educational purposes.

| Column | Description |
|---|---|
| `Patient_ID` | Unique sample patient identifier |
| `Age` | Patient age in years |
| `Gender` | Patient gender |
| `Medical_Condition` | Recorded sample condition |
| `Hospital` | Sample hospital name |
| `Treatment_Cost` | Illustrative treatment cost |

**Note:** The dataset is fictional and does not contain real patient records or verified hospital prices. It is intended only for learning and demonstration.

## 📈 Analysis and Visualizations

This project includes:

- Patient count by gender
- Patient age distribution
- Medical conditions comparison
- Treatment cost by hospital
- Age vs. treatment cost analysis
- Summary statistics and group-wise analysis

## ⚙️ Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run

1. Clone or download this repository.
2. Ensure `healthcare_data.csv` is inside the `data` folder.
3. Open a terminal in the project directory.
4. Run the Python script:

```bash
python healthcare_analysis.py
```
